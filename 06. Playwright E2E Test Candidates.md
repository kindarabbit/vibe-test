## 2. Detailed Test Candidates

### E2E-001. Create script from valid inputs

- Requirement: FR-001, FR-002, FR-003, FR-004
- OpenSpec: Script source input, Tone selection, Duration selection, Mock script generation
- Flow:
  1. Open `/app`.
  2. Clear `localStorage`.
  3. Fill title.
  4. Fill PPT content or presentation keywords.
  5. Select tone, for example `공식적으로`.
  6. Select duration, for example `10분`.
  7. Click `대본 생성`.
- Assertions:
  - Generated script title is visible.
  - Selected tone is visible.
  - Selected duration is visible.
  - Source keyword appears in generated script content.
  - New script appears in generated script list.
- Suggested Playwright name: `creates a presentation script from required inputs`

### E2E-002. Show validation for missing required inputs

- Requirement: FR-001
- OpenSpec: User omits required script inputs
- Flow:
  1. Open `/app`.
  2. Clear `localStorage`.
  3. Click `대본 생성` without filling required fields.
- Assertions:
  - Validation message is visible.
  - No generated script is added to the list.
  - Empty state remains visible.
- Suggested Playwright name: `shows validation when required inputs are missing`

### E2E-003. Show generated script preview

- Requirement: FR-004
- OpenSpec: Generated script appears in preview
- Flow:
  1. Create a script with valid inputs.
  2. Observe preview area.
- Assertions:
  - Preview shows title, tone, duration, status, and content.
  - Status starts as `작성 중`.
  - Preview content is split into readable paragraphs.
- Suggested Playwright name: `shows generated script preview details`

### E2E-004. Show generated script in list

- Requirement: FR-005
- OpenSpec: Scripts exist
- Flow:
  1. Create one or more scripts.
  2. Scroll or move to list area.
- Assertions:
  - Each script card shows title.
  - Each script card shows source summary.
  - Each script card shows tone, duration, and status.
- Suggested Playwright name: `shows generated scripts in the list`

### E2E-005. Show empty state when no scripts exist

- Requirement: FR-004, FR-005
- OpenSpec: No scripts exist
- Flow:
  1. Open `/app`.
  2. Clear `localStorage`.
  3. Reload.
- Assertions:
  - Empty state heading is visible.
  - Empty state explains how to create the first script.
  - No script card is visible.
- Suggested Playwright name: `shows empty state before any script is created`

### E2E-006. Change script status

- Requirement: FR-006
- OpenSpec: User changes script status
- Flow:
  1. Create a script.
  2. Click `상태 변경`.
- Assertions:
  - Status changes from `작성 중` to `검토 중`.
  - Status is reflected in preview.
  - Status is reflected in list card.
- Suggested Playwright name: `updates status and reflects it in preview and list`

### E2E-007. Filter scripts by status

- Requirement: FR-007
- OpenSpec: User filters scripts
- Flow:
  1. Create a script.
  2. Change its status to `검토 중`.
  3. Select `검토 중` status filter.
  4. Select a status filter with no matching item, for example `완료`.
- Assertions:
  - Matching script remains visible under matching filter.
  - No-results empty state appears under non-matching filter.
- Suggested Playwright name: `filters scripts by status`

### E2E-008. Filter scripts by tone and duration

- Requirement: FR-007
- OpenSpec: User filters scripts
- Flow:
  1. Create script A with `공식적으로`, `10분`.
  2. Create script B with `친근하게`, `5분`.
  3. Select tone filter.
  4. Select duration filter.
- Assertions:
  - Only matching scripts are visible.
  - Non-matching scripts are hidden.
  - No-results empty state appears when combined filters have no match.
- Suggested Playwright name: `filters scripts by tone and duration`

### E2E-009. Search scripts by keyword

- Requirement: FR-007
- OpenSpec: User filters scripts
- Flow:
  1. Create a script with a unique source keyword.
  2. Type keyword into search input.
- Assertions:
  - Matching script is visible.
  - Unmatched scripts are hidden.
  - No-results empty state appears for a keyword with no match.
- Suggested Playwright name: `searches scripts by keyword`

### E2E-010. Copy generated script content

- Requirement: FR-008
- OpenSpec: User copies script content
- Flow:
  1. Create a script.
  2. Click `대본 복사`.
- Assertions:
  - Button changes to `복사 완료`.
  - Clipboard contains generated script content.
- Suggested Playwright name: `copies generated script content`

### E2E-011. Persist scripts after reload

- Requirement: NFR-004, Local persistence
- OpenSpec: User reloads the app
- Flow:
  1. Create a script.
  2. Reload page.
- Assertions:
  - Previously created script remains in list.
  - App does not crash.
  - Preview area does not need to auto-open unless the current UX explicitly requires it.
- Suggested Playwright name: `persists generated scripts after reload`
